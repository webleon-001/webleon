1. ツールの概要
ブラウザ上で完結する画像一括処理ツールです。読み込んだ画像を自動で幅1200pxにリサイズし、色調補正・分割・ロゴ合成・プリセットキャンバス管理などの編集を行い、ZIPで一括書き出しできます。すべての処理はローカルで完結し、画像データが外部サーバーに送信されることはありません。
2. 使用方法

📥 ファイルの読み込み

  • 対応形式： JPG / PNG / WEBP / GIF / HEIC / TIFF / PDF / PSD / AI / ZIP
  • アップロードゾーンへのドラッグ＆ドロップ、またはクリックによるファイル選択で読み込みます。画像追加後も「画像追加」ボタンでいつでも追記できます。
  • ZIPは中の画像を自動展開してリストに追加します。
  • PDF・PSD・AIはレイヤーを解析・変換して読み込みます（AIはPDF互換形式のみ対応）。

🎨 画像の調整・編集

  • 比率変更： オリジナル・3:2・4:3・1:1・3:4・2:3 から選択。元画像と同比率のボタンは自動で無効化されます。
  • 色調補正： 彩度・明るさ・シャープネス・回転をスライダーで調整。各スライダー横の ↺ ボタンで前回保存値に復元できます。
  • ズーム・移動： プレビュー上でドラッグして位置調整、マウスホイールまたはズームボタンで拡大縮小（拡大のみ・最大500%）。ズーム入力欄に数値を直接入力することもできます。
  • ファイル名編集： プレビュー中央のファイル名をクリックするとその場でリネームできます。
  • ガイド： グリッドのほか、小さい画像向けに 800px・400px の基準ガイドを表示できます。
  • 保存： 編集後は「保存」ボタンで確定します。未保存の変更があるとボタンが赤く点滅します。

🧩 分割モード（コラージュ）

  • 「分割」ボタンから縦・横それぞれ 2〜4 分割を選択。複数の画像を1枚のキャンバスにまとめられます。
  • 各枠に画像をドラッグ＆ドロップして割り当て、枠ごとに拡大縮小・移動・色調補正が独立して行えます。

✨ 透過（ロゴ）合成

  • 「透過」ボタンでロゴパネルを開きます。PNG・PSD・AI・PDF からレイヤーを抽出してライブラリにストックできます。
  • 配置したロゴはドラッグで移動、角のハンドルで拡大縮小・回転が可能。カラーピッカーでロゴを単色に変換することもできます。

🖼️ プリセットキャンバス（Thumbnail / OG / Special）

  • サムネイル一覧からプリセットキャンバスに画像をドラッグ＆ドロップすると、そのキャンバスが自動で開きます。
  • プリセット同士でも相互にドラッグ＆ドロップでコピーできます。
  • プリセットキャンバスをクリックすると、割り当て済みの画像が専用アスペクト比で開きます（未割り当ての場合はガイドダイアログが表示されます）。
  • 編集中のプレビューから「Thumbnail」「OG」「Special」ボタンを押すと、現在の状態をそのままプリセットに保存できます。

💾 スロット（1〜10）

  • 画面右上のスロットセレクターで、作業状態を丸ごと保存・切り替えできます。
  • 鉛筆アイコンでスロット名を変更、ゴミ箱アイコンでそのスロットを初期化できます。

🔤 ファイル名管理

  • ファイル名で検索： 検索欄に入力するとリアルタイムでサムネイルを絞り込み表示します。
  • ファイル名を連番： ボタンを押すと全画像のファイル名を 1.jpg, 2.jpg … と自動採番します。Shift＋クリックで元のファイル名にリセットします。
  • 全角文字を含むファイル名は書き出し時に自動検出され、半角英数字への変換や連番への一括置換が可能です。

📦 書き出し

  • ZIP で書き出し： 編集済みの全画像を1つのZIPにまとめてダウンロードします。
  • フォルダに書き出し（Shift＋クリック）： ローカルフォルダを直接指定して保存できます（対応ブラウザのみ）。
  • この画像を書き出す： プレビュー中の1枚だけを単体で書き出します（Shift＋クリックでフォルダ保存）。
  • 幅1200px未満の画像がある場合、書き出し前に「そのままのサイズ」か「拡大して書き出す」かを選択できます。

📱 QRコード生成

  • 右上の QR アイコンから URL を入力してQRコードを生成・ダウンロードできます。
